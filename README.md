# Тихая высота

Личный сайт для музыки и сосредоточенной учёбы на большом экране.

## Возможности

- Пейзаж в стиле альпийских гор: закат, туман, дождь, ночь; мягкое движение.
- Фиксированная атмосфера или автоматическая смена каждые 10, 20, 30 минут. Ручной выбор отключает автоматическую смену. Настройки атмосферы сохраняются на устройстве.
- Иллюстрированный атлас изученных тем Go: семь мест и короткие ассоциации к 12 темам. Карта статична: нет конспектов, тестов, повторений или редактирования прогресса.
- Три оригинальные синтезированные композиции, загрузка своего аудио до 25 МБ, создание плейлистов, порядок, перемешивание, повтор и перемотка.
- Серверное хранение личной библиотеки и плейлистов (D1 + R2), доступ по аккаунту ChatGPT. Конкурирующее сохранение защищено номером ревизии.
- Таймер фокуса, полный экран, режим без интерфейса, навигация стрелками/Enter, выход по Esc/Back.

## Запуск

Node.js >= 22.13, npm, Git. Все команды из корня проекта.

```sh
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_smooth_jackpot.sql
npm run dev
```

Открыть адрес, который напечатает сервер (обычно http://localhost:5173). Для локального хранилища нажать «Войти» — используется тестовая личность только в локальной разработке. Миграцию на одной локальной базе выполнять один раз.

Для телевизора нужен опубликованный HTTPS-адрес; localhost телевизора не является адресом компьютера. Опубликованный сайт закрытый: войти на телевизоре тем же аккаунтом. Физический Smart TV пока не проверен; поддержка полного экрана и аудиоформатов зависит от браузера. MP3 наиболее совместим. Воспроизведение начинается после нажатия кнопки.

## Проверка

```sh
npx tsc --noEmit
npm run lint
node --experimental-strip-types --test tests/world.test.ts
python3 scripts/smoke-test.py
npm run build
```

Smoke test требует работающего локального dev-сервера и миграции; проверяет авторизацию, плейлисты, ревизии, загрузку аудио и Range. Создаёт тестовый трек в локальной библиотеке; продакшен не затрагивает.

## Материалы

Горные иллюстрации созданы по референсам пользователя. Оригинальные синтезированные MP3 создаются `python3 scripts/create-audio.py` (нужен ffmpeg); внешние сэмплы не используются. Для перерисовки карты подписи и позиции находятся в `app/world.ts`.
