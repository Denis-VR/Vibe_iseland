# Тихая высота / Vibe Island

Самостоятельный сайт для компьютера и браузера Smart TV. Музыка и изображения хранятся вместе с сайтом; реальная погода получает данные Open-Meteo.

## Что внутри

- Сезонные иллюстрации одной долины — весна, лето, осень, зима, а также рассвет, ясный день, туман, дождь, закат, звёздная ночь. Ночью видны звёзды и светятся домики.
- Ручная смена пейзажа за 1,8 секунды, автоматическая — за 12 секунд. При быстром переключении переход начинается с текущего кадра; последний выбор побеждает. Перед переходом изображение загружается; прежний пейзаж остаётся под новым. Облачные слои медленно перемещаются за 4–5,5 минуты. Это анимированные иллюстрации, не видео или 3D: облака дополнительно двигаются отдельным слоем, дома нарисованы в сценах.
- Фиксированное условие или автосмена через своё число минут (целое от 1 до 1440). Ручной выбор отключает автосмену.
- Двенадцать звуков: белый, розовый, коричневый шум, редкие капли дождя, ливень, дождь по крыше, ветер, водопад, тихий лесной ручеёк, птицы, костёр, деревенский двор с курами. Костёр, ручеёк, редкий дождь и двор основаны на полевых записях CC0; остальные каналы синтезируются. Источники и обработка — [public/audio/SOURCES.md](public/audio/SOURCES.md). Независимые уровни, общая громкость, регулировка мягкости синтезированного шума. Кнопка «Отдельно» оставляет только выбранный канал микшера. Звуки не зависят от выбранной погоды. Сохранённый микс включается вручную.
- Изображения перерисованы с более чёткими деталями и сохранены в WebP без потерь. Исходное разрешение генерации — 1672×941; это не нативные 4K-кадры.
- Девять встроенных музыкальных композиций по 4 минуты (36 минут), плейлисты, повтор, перемешивание и перемотка.
- Крупный таймер сессии, видимый и в режиме без интерфейса.

Публичная версия: **https://vibeisland.fun**. Обслуживание сервера, HTTPS и статистика: [deploy/README.md](deploy/README.md). Загрузка своих треков отключена.

## Запуск

Нужен Node.js **24 или новее**.

```sh
npm ci
npm run build
npm start
```

Открыть **http://localhost:4173**. Для разработки: `npm run dev` (порт 5173).

Для телевизора в той же домашней сети:

```sh
HOST=0.0.0.0 npm start
```

Открыть `http://IP-КОМПЬЮТЕРА:4173` на телевизоре. Компьютер должен оставаться включённым. `localhost` на телевизоре означает сам телевизор. Управление: стрелки, Enter, Esc/Back. На физическом Smart TV ещё не проверено; воспроизведение требует первого нажатия. MP3 наиболее совместим. Нужен браузер с Web Audio для микшера.

## Перенос на сервер

Скопировать проект без `node_modules`, `.git`, `.wrangler`, `dist`, затем выполнить `npm ci`, `npm run build`, `npm start`. Для переноса музыки и плейлистов остановить процесс и скопировать **всю папку `data/`** вместе с приложением. Данные прежнего опубликованного сайта автоматически не загружаются; его хранилище остаётся отдельным.

- `data/quiet-height.sqlite` — библиотека и плейлисты; рядом могут быть SQLite WAL-файлы.
- `data/audio/` — загруженные файлы. Пересборка сайта не удаляет их.
- `DATA_DIR` меняет папку данных, `PORT` — порт, `HOST` — адрес прослушивания.
- По умолчанию библиотека одна общая для этого экземпляра сервера, без аккаунтов.
- Для закрытого доступа на своём сервере задай `ACCESS_PASSWORD` и используй HTTPS через reverse proxy. Браузер спросит пароль; имя пользователя может быть любым. Reverse proxy должен передавать исходный `Host` (загрузка своих файлов отключена).

Обновлять сайт: остановить процесс, заменить исходники, выполнить `npm ci && npm run build`, запустить снова. Папку `data/` сохранять.

## Проверки

```sh
npx tsc --noEmit
npm run lint
node --experimental-strip-types --test tests/world.test.ts tests/noise.test.ts tests/noise-engine.test.ts tests/local-server.test.mjs
```

Серверные тесты используют отдельные временные SQLite-базы: проверяет пароль, запрет чужого Origin, сохранение и конфликт ревизий, запрет загрузки, изоляцию плейлистов в публичном режиме, Range/HEAD, восстановление библиотеки после перезапуска и наличие всех изображений. Пользовательскую библиотеку не меняет.

`app/landscape.tsx` — переходы сцен; `app/noise-engine.ts` — Web Audio; `app/world.ts` — порядок погоды; `server/index.mjs` — самостоятельный HTTP-сервер с SQLite и файловым хранилищем.

Файлы прежней облачной интеграции сохранены в репозитории, но `npm start`, `npm run dev` и `npm run build` их не используют. В этой версии ничего не публикуется.

## Посещения и выбранные места — только для владельца

Ничего из статистики не отображается на сайте. В той же SQLite-базе хранятся:
- `visits`: открытия страницы, время UTC, случайный идентификатор браузера, приблизительные страна/регион/город по IP;
- `place_choices`: отдельно каждое подтверждённое место для погоды, страна, регион, источник выбора (`manual` / `geolocation`). Переключение уже выбранного режима и обновления погоды новых выборов не создают.

Посмотреть последние 30 дней (число можно менять):
```sh
npm run stats -- 30
```
Вывод — JSON: посещения, уникальные браузеры, дни, география посещений и отдельно выбранные города. Доступ только через файловую систему сервера; публичного API чтения нет. Данные переживают перезапуски. Их нужно переносить вместе с папкой `data/`. Сбор начинается после этого обновления, историю старого сайта восстановить нельзя.

Посещение — одно открытие/перезагрузка страницы с выполненным JavaScript. Повторы одного события не считаются; переключения сцен не считаются посещениями. Это не точное число людей: приватный режим, разные устройства, удаление localStorage и боты влияют на число браузеров. Сетевые сбои могут потерять событие. IP и точные GPS-координаты в базу не записываются. Для localhost/частных IP география будет `unknown`; VPN может показывать регион провайдера. География по IP и выбранное место намеренно независимы.

По умолчанию заголовки прокси не используются. Если nginx работает **на той же машине**, запускай Node с `HOST=127.0.0.1 TRUST_PROXY=1`, а в nginx устанавливай (перезаписывай) `proxy_set_header X-Real-IP $remote_addr;` и `proxy_set_header Host $host;`. Приложение доверяет этому заголовку только от loopback. Для внешнего прокси/CDN нужна отдельная проверенная настройка доверенных адресов, иначе сохраняй режим без TRUST_PROXY. Логи самого nginx настраиваются отдельно от базы приложения.

## Местная погода и таймер

В «Атмосфере» можно выбрать город или нажать «Моё местоположение». Геопозиция запрашивается только по нажатию; требуется HTTPS либо localhost. На телевизоре через обычный HTTP доступен ручной выбор города. Ближайший город определяется локальным справочником; его центр передаётся Open-Meteo, а не точная GPS-точка. Город и режим сохраняются в браузере. Справочник охватывает города от 15 тысяч жителей и столицы; для маленького населённого пункта выбирается ближайший город (до 150 км).

Погода обновляется раз в 15 минут, положение относительно восхода/заката проверяется каждые 30 секунд по часовому поясу города. В пределах 45 минут от восхода/заката включается соответствующий свет, ночью — ночная сцена, днём снег включает зиму, осадки — дождь, туман — туман. Сцены художественно передают условия, а не воспроизводят реальный вид выбранного города. При ошибке остаётся предыдущая сцена и показывается сообщение. Выбор условия вручную выключает режим местной погоды.

Свою сессию можно задать целым числом минут от 5 до 525600 (365 дней). «Выбрать» меняет длительность; «Начать сессию» запускает её. Крестик у таймера полностью убирает сессию, оставляя музыку. Таймер рассчитывается по абсолютному времени и переживает фоновое замедление вкладки, но сбрасывается при перезагрузке страницы; открытая годовая сессия не означает гарантии непрерывного браузерного исполнения.

Источники географии и погоды: `server/SOURCES.md`. Геопозиция пользователя и физический Smart TV требуют проверки на соответствующем устройстве.

### Сезоны и выравнивание музыки

Выбор города теперь только сохраняет место. Нажми **«Включить реальный режим»**, чтобы сразу запросить погоду и применить сезон и освещение (плавный переход около 1,8 секунды после ответа сервиса). Есть отдельное выключение. При смене города режим ждёт нового нажатия; выбор не запускает его сам.

Весна, лето, осень и зима определяются календарём в часовом поясе города с учётом полушария. Это календарная художественная интерпретация, не измерение листвы или снежного покрова; текущий снег включает зимний вариант. Ночь, рассвет, закат, дождь и туман сохраняют сезонный ландшафт: у сезонных кадров освещение и дымка компонуются в canvas. Вручную доступны весенняя и осенняя сцены; летняя обновлена. Сезонные изображения созданы встроенным imagegen, пути и точные промпты: `public/scenes/generation.json`.

Все 9 встроенных композиций выровнены двухпроходным FFmpeg loudnorm до целевого −21 LUFS, с ограничением true peak −2 dBTP. Итоговые измерения: `public/audio/loudness.json`. Сайт играет файлы из `public/audio/leveled/`, исходники остаются в `public/audio/`. Для повторной подготовки нужен локальный ffmpeg и `python3 scripts/normalize-music.py`; для обычного запуска ffmpeg не нужен. Пользовательские загрузки автоматически не нормализуются.
